# gateway-service

API‑шлюз для мультисервисной системы управления пользователями и уведомлениями. Выступает единой точкой входа для внешних клиентов, обеспечивает маршрутизацию запросов, обнаружение сервисов и отказоустойчивость.

## 📋 Возможности

*   **Единая точка входа (Single Entry Point)** — все внешние запросы проходят через шлюз.

*   **Динамическая маршрутизация** — запросы автоматически перенаправляются к целевым микросервисам на основе URL‑префиксов (`/user-service/...`, `/notification-service/...`).

*   **Прозрачная передача статусов и ошибок** — шлюз корректно пробрасывает HTTP‑статусы (200, 404, 500 и т.д.) и тела ответов от целевых сервисов без искажения семантики API.
